# Monkey Language

An implementation of the Monkey programming language written in Go while
working through [*Writing An Interpreter In Go*](https://interpreterbook.com/)
by Thorsten Ball.

This repository documents what I am learning about lexers, parsers, abstract
syntax trees, and interpreters. It is a work in progress and currently includes
a lexer, parser, AST, and an interactive REPL that prints tokens.

## Run the REPL

```sh
go run .
```
